# ActivitySim population identity and join records

`activitysim_population.yaml` describes the ActivitySim-owned household,
person, and land-use-zone identity fields observed by the current PILATES
adapter. It is a partial set of join fields, not a complete ActivitySim input
schema or a shared-kernel definition.

`member_id` is intentionally marked as regenerated by ActivitySim
preprocessing. Work and school aliases are scoped only to the current PILATES
ActivitySim adapter, while `TAZ` preserves the observed physical column name.

`activitysim_skims.yaml` (`ActivitySimNetworkSkims`) defines the canonical
production Open Matrix (`skims.omx`, `OMX_VERSION = '0.2'`, `SHAPE = [N_zones, N_zones]`,
`/data` 2D OD matrices and `/lookup` 1D zone index lookup tables) and Zarr
(`.zarr`) 3D `[time_period, origin_zone, destination_zone]` travel skim array
contract consumed by ActivitySim. Note that the classification of `DIST`,
`DISTWALK`, `SOV_*`, and `WLK_TRN_WLK_*` as `required: true` and all other mode
families as `required: false` is marked provisional and should be verified
against target regional model configurations.
