# Costs and exit

Steady-state receipt work is minutes, not hours: budget roughly five minutes
to emit and inspect a known exchange, plus normal review time for semantic
change. The first encode-and-return target is five business days.

You may exit at any point. The exit-cost guarantee preserves payloads, readable tables, and inert manifests; removing Synergy-specific checking does not make the exchanged files unreadable.

For a stable one-off, flat files plus a README can be enough; this contract is
an optional escalation for repeated or changing exchanges.
