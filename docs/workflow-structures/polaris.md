# POLARIS translated population

POLARIS is an agent-based travel demand and dynamic network traffic simulation
engine. In integrated studies, it consumes synthetic populations translated from
upstream modeling outputs to simulate regional traffic flow and congestion.

## Current

POLARIS native records are partial in this schema. They support a synthetic
translation-receipt example and focused interface checks, not a claim of
complete model coverage.

## Proposed

The receipt records five yearly artifact roles, the source population bundle,
the reviewed one-year mapping, the registered translation implementation, and
any documented scenario gaps. These links allow a checker to compare the
translation with the source scenario and year.

## Out of scope

POLARIS runtime adapter enforcement is future work. This repository does not
claim a deployed POLARIS runtime, automatic receipt emission, or model-team
approval.
