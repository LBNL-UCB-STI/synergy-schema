# POLARIS translated population

## Current

POLARIS native records are partial in this schema: they support a translation
receipt example, not a claim of complete model coverage.

## Proposed

The receipt records five yearly roles, source bundle identity, the one-year
mapping release, and documented compatibility gaps.

## Out of scope

POLARIS runtime adapter enforcement is future work. This repository does not
claim a deployed POLARIS runtime or model-team approval.
