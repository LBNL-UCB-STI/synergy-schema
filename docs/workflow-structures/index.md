# Workflow structures

These [workflow profiles](../shared-structure/glossary.md#workflow-profile)
compose shared structure with
[model-native records](../shared-structure/glossary.md#native-record). They are
proposed exchange contracts, not runtime integrations.

Ownership follows the boundary: model teams own native meanings, workflow
teams own orchestration and translation behavior, and Synergy owns the shared
vocabulary and its checks. See [ownership and
authority](../shared-structure/glossary.md#ownership-and-authority) for the
full responsibility table.
