# Are flat files enough?

Often, yes. A stable one-off exchange can be perfectly clear with flat files,
a README, and names of people to contact. More structure is worth it when
deliveries repeat, scenario branches multiply, mappings change, or several
teams need to piece together what happened long after the fact.

The first things worth adding are usually file fingerprints and a readable
mapping description. Interface catalogs, review records, code links, and
receipts become worthwhile once the confusion they prevent has become a real
problem. Synergy supports adding pieces gradually; no exchange has to use
every record.
