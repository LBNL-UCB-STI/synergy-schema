# Are flat files enough?

Often, yes. A stable one-off exchange can be clear with flat files, a README,
and named contacts. More structure earns its cost when delivery repeats,
scenario branches multiply, mappings change, or several teams must reconstruct
what happened after the original exchange.

The first useful additions are usually exact file identity and a readable
mapping description. Interface catalogs, review records, implementation links,
and receipts become worthwhile when the corresponding ambiguity has become a
real coordination risk. Synergy supports that gradual path; it does not require
every exchange to use every record.
